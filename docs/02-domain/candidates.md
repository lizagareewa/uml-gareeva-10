| Существительное из сценария | Решение | Почему |
| :--- | :--- | :--- |
| Место | Класс | Имеет состояние, ряд, номер и историю блокировок. |
| Касса | Класс | Обладает идентичностью (номер) и инициирует операцию блокировки. |
| Блокировка | Класс-ассоциация | Атрибут времени зависит от связи между конкретной кассой и местом, а не от них по отдельности. |
| Билет | Класс | Представляет физический или электронный объект с уникальным штрихкодом. |
| Абонемент | Класс | Отличается от билета сроком действия на серию событий. |
| Заказ | Класс | Объединяет выбранные билеты и фиксирует факт продажи. |
| Комиссия | Атрибут | Вычисляемая денежная сумма, не имеет собственного поведения и жизненного цикла. |
| Возврат | Класс | Имеет дату оформления, фиксирует факт отмены билета. |
| Покупатель | Класс | Имеет ФИО и контактные данные для связи. |
