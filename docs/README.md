Система продажи билетов на стадион обслуживает продажу нумерованных мест на спортивные и концертные события. Билеты продаются через кассы на стадионе и удалённо; несколько касс могут работать параллельно, поэтому при выборе места оно временно блокируется на время оплаты, чтобы два зрителя не купили одно и то же место. Поддерживаются возврат билетов и продажа сезонных абонементов, дающих право прохода на серию матчей без покупки отдельного билета на каждый.
