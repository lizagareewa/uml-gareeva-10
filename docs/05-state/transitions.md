### Находки по итогам построения таблицы

1. **Отмена уже оплаченного заказа до выдачи билета.** В сценариях ПЗ1 я рассматривала только возврат уже готового билета (ВИ-03). При заполнении таблицы стало очевидно, что не хватает сценария, когда зритель отменяет заказ сразу после оплаты, пока PDF-файл еще в процессе генерации. Добавлен переход из Оплачен в Отменён с действием вернутьДеньги().
2. **Возврат со штрафом.** В ПЗ1 было описано исключение для возврата менее чем за 3 дня (с удержанием комиссии). В автомате это требовало явного разделения. В таблицу добавлена вторая строка для перехода из Выполнен в Возврат со сторожевым условием [до матча <= 3 дней] и обязательным действием удержатьКомиссию(), чтобы модель логически не ломалась.
