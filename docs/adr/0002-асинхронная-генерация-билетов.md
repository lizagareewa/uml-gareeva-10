# ADR-0002. Асинхронная генерация и отправка билетов через RabbitMQ

**Дата:** 2026-10-06
**Статус:** принято

## Контекст
После успешной оплаты заказа системе необходимо сгенерировать PDF-билеты со штрихкодами и отправить их на email зрителя. Эти операции (генерация PDF и сетевой запрос к почтовому шлюзу) могут занимать несколько секунд.

## Рассмотренные варианты
1. Синхронное выполнение: Backend API генерирует PDF и шлет email прямо в потоке обработки HTTP-запроса, и только потом возвращает ответ пользователю.
2. Асинхронное выполнение: Backend API публикует событие `OrderCreated` в брокер сообщений (RabbitMQ), а отдельный Воркер в фоне обрабатывает генерацию и рассылку.

## Решение
Вариант 2 (Асинхронная обработка через RabbitMQ).

## Последствия
**Плюсы:** быстрый ответ пользователю об успешной оплате. Повышение отказоустойчивости: если почтовый шлюз недоступен, сообщения останутся в очереди и Воркер повторит отправку позже, заказы не потеряются.
**Минусы:** усложнение инфраструктуры (появляется RabbitMQ и новый контейнер Воркера), усложняется отладка процессов.
**Что станет неверным, если решение пересмотреть:** диаграмма контейнеров (уровни 2 и 3 С4), сценарий покупки на диаграмме динамического вида.
